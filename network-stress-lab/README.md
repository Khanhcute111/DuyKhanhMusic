# Network Stress Lab

A defensive, tightly bounded HTTP load-testing dashboard for websites you own or are explicitly authorized to test.

## Safety controls

- HTTPS only; default port 443 only.
- Exact hostname allowlist via `ALLOWED_TARGET_HOSTS`.
- Rejects IP literals, non-public DNS results, private/loopback/link-local destinations, URL credentials and fragments.
- Redirects are not followed.
- Admin API requires a bearer token stored as a Render secret.
- Hard caps: 40 requests, 10 seconds, 4 concurrent workers.
- One active run at a time and 30-second cooldown.
- No arbitrary payloads, UDP, raw sockets, spoofing, reflection, amplification or distributed agents.

This is a small application-level performance smoke test, not a DDoS simulator and not a substitute for a professional resilience assessment.

## Deploy on Render

Create a Blueprint using this file: `network-stress-lab/render.yaml`.

Set two environment variables during service setup:
- `STRESS_LAB_TOKEN`: a long random secret generated by you.
- `ALLOWED_TARGET_HOSTS`: comma-separated exact hostnames you own, e.g. `example.com,www.example.com` (hostnames only; no scheme or path).

Do not commit secrets to GitHub. Keep the allowlist limited to domains you control.

## Local run

```bash
cd network-stress-lab
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
export STRESS_LAB_TOKEN='replace-with-a-long-random-secret'
export ALLOWED_TARGET_HOSTS='example.com'
uvicorn app:app --reload
```

Open http://127.0.0.1:8000.
